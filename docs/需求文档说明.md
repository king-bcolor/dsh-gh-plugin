# gh CLI DeepSeek Harness 插件 — 需求文档说明

## 1. 项目定位
把 GitHub CLI（`gh`）封装为 DeepSeek Harness 插件，让 Agent 在对话中执行 GitHub 操作：仓库、issue、PR、搜索、Actions、Release、API。

## 2. 用户角色
| 角色 | 说明 |
| --- | --- |
| 终端用户 | 在 DSH Web UI 中管理 GitHub 工作项 |
| Agent/模型 | 通过工具 schema 调用 gh 命令并读取 JSON 结果 |
| 开发者 | 安装、配置、扩展插件 |

## 3. 功能需求
### FR-1 认证
- FR-1.1 提供 `gh auth status` 工具，返回登录状态、账号、token scope。
- FR-1.2 未认证时返回明确错误与登录提示。

### FR-2 仓库
- FR-2.1 提供仓库创建工具（`repo create`），支持可见性、描述、推送。
- FR-2.2 提供仓库查看/列表/编辑工具（`repo view/list/edit`）。
- FR-2.3 提供仓库删除工具（`repo delete`），必须二次确认。
- FR-2.4 提供标签维护工具（`repo edit --add-topic/--remove-topic`）。

### FR-3 Issue
- FR-3.1 提供 issue 创建/列表/查看/关闭/重开/评论/编辑工具。

### FR-4 Pull Request
- FR-4.1 提供 PR 创建/列表/查看/合并/检出/审查/关闭/重开工具。

### FR-5 搜索与 API
- FR-5.1 提供仓库/issue/PR/代码搜索工具。
- FR-5.2 提供 `gh api` 工具，允许指定路径、方法、字段与 `--jq` 过滤。

### FR-6 Actions 与 Release
- FR-6.1 提供 workflow/run 查看工具。
- FR-6.2 提供 release 创建/列表/查看工具。

## 4. 非功能需求
| 编号 | 需求 |
| --- | --- |
| NFR-1 | 全程 TDD，测试先行。 |
| NFR-2 | 所有工具 JSON 优先，渲染为可读文本。 |
| NFR-3 | 不得把 `GH_TOKEN` 写入日志、模型上下文或仓库。 |
| NFR-4 | 超时默认 30s，可配置。 |
| NFR-5 | `ghBin` 可配置，默认 `gh`。 |
| NFR-6 | 危险操作（repo delete、issue delete、pr merge）默认确认。 |
| NFR-7 | 支持 `gh` 不在 PATH 时给出安装指引。 |

## 5. 用户交互逻辑
1. 首次使用：安装插件 → 检查 `gh auth status` → 未登录则引导用户运行 `gh auth login`（或使用 GH_TOKEN）。
2. 浏览：Agent 调用 list/view → UI 表格展示。
3. 创建：表单填写 title/body → 工具调用 → 展示链接。
4. 危险操作：UI 弹确认框 → `confirm: true` 后执行。
5. 错误处理：未认证、权限不足、参数错误映射为结构化错误与 UI Alert。

## 6. 数据交互面板清单
| 面板 | 数据来源 | 主要数据字段 |
| --- | --- | --- |
| 认证面板 | auth status | 账号、hostname、token scope、协议 |
| 仓库面板 | repo list/view | fullName、描述、stars、topics、默认分支 |
| Issue 面板 | issue list/view | number、title、state、labels、body、comments |
| PR 面板 | pr list/view | number、title、state、author、base/head、mergeable |
| 搜索面板 | search repos/issues/prs/code | 查询串、类型、结果列表 |
| Actions 面板 | workflow/run list/view | workflow、databaseId、status、conclusion、日志 |
| Release 面板 | release list/view/create | tag、name、notes、发布日期 |
| API 调试面板 | gh api | 路径、方法、jq、响应 JSON |
| 确认对话框 | delete/merge 等 | 操作对象、确认参数 |

## 7. 验收标准
- 每个 FR 至少一条自动化测试。
- `gh` 未安装或未认证时返回明确错误。
- 危险操作 confirm=false 时拒绝执行。
- `dsh plugin add` 安装成功并可 dump-config 可见。
- 中英文 README 开头互相引用。
