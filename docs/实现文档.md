# gh CLI DeepSeek Harness 插件 — 实现文档

## 0. 全程使用 TDD
本项目严格遵守 TDD：
1. Red：根据用例目录/需求文档编写失败测试。
2. Green：最小实现使测试通过。
3. Refactor：重构保持全绿。
4. 每个工具先有测试，后有实现；提交信息先 `test:` 后 `feat:`。
5. runner 与参数映射使用 fake `gh` fixture 覆盖；危险确认、JSON 解析、超时、非 0 退出、缺 gh 均有自动化测试。

## 1. DeepSeek Harness 插件机制
- Cordis 插件：`index.js` 导出 `name`、`inject`、`apply(ctx, config)`、`Config`。
- 工具注册：`inject = ['tools']`，`apply` 中调用 `ctx.tools.register(defineTool({...}))`。
- Host Remote：`apply` 中 `ctx.plugin(GhRemoteService)`；Typert Gateway SRC 模式暴露 `/api/gh/catalog|status|execute`。
- 浏览器 UI：`package.json` 的 `dsh.client` 指向 `lib/client.js`，在 Settings 注册 **GitHub** 控制台。
- 配置：Schemastery `Config`，包含 `ghBin`、`timeoutMs`、`confirmDangerous`。
- 发布：npm 包 + `dsh.bundle.patch` + `cordis.patch.yml`。

## 3. 架构
```
Agent → tools.execute(name, arguments)
      → defineTool.execute(args)
      → 校验 args（defineTool 内置 JSON Schema 校验）
      → 参数映射为 gh argv 数组
      → spawn(ghBin, args)（无 shell，30s 超时，超时杀进程组）
      → stdout 按需 JSON.parse（--json / gh api）
      → 返回 canonical value
      → output.render 渲染为 text 内容块
```

## 5.1 浏览器 UI
- `lib/client.js` 使用 DSH client module loader（`window.__ModuleLoader__.load`）。
- 注册 slot：`settings.section`（设置页控制台）和 `conversation.view`（会话主视图 GitHub 标签页）。
- UI 通过 `ctx.connection.rpc.call('/api', 'gh/catalog', ...)` 拉取全部工具元数据，动态生成表单，不写死单个工具。
- `gh/status` 展示认证状态；`gh/execute` 执行 gh 并展示 JSON/文本结果。
- 会话主视图提供 `gh/profile`、`gh/repositories`、`gh/inbox`、`gh/branches`、`gh/repoBranches`：热力图、仓库操作、收件箱与 Git 分支。
- 依据官方 `docs/subsystems/client-modules.md`：包声明 `dsh.client` + `exports[\"./client\"]`；依据 gateway client 契约，浏览器插件直接使用 connection RPC，而不是假设未挂载的 `ctx.remote.*` 命名空间。
- 危险工具（`repo delete`、`pr merge`、`gh api` 写方法）在 UI 中必须勾选确认。

## 6. 核心实现要点
### 6.1 runner
- `spawn(ghBin, args)`，参数数组传递，杜绝 shell 注入。
- 默认超时 30000ms；超时后杀掉整个进程组，避免 git 等子进程残留。
- `gh` 不存在时抛出 `GH_NOT_FOUND`，消息包含安装指引。
- 非 0 退出不抛异常，返回结构化结果；退出码 4 映射为未认证提示。
- stdout 由工具声明是否解析为 JSON；普通文本原样返回。
- 不读取/打印 `GH_TOKEN` 值，env 原样透传。

### 6.2 安全
- `repo delete`、`pr merge` 等工具要求 `confirm: true`。
- `gh_api` 方法白名单：GET/POST/PATCH/DELETE；默认允许 GET，写方法需 `confirm: true`。
- `confirmDangerous: false` 可关闭确认，但默认开启。
- 工具 description 中提醒模型不得输出 token。
