# gh CLI 插件用例文档说明

## 1. 文档目的
本文档沉淀 `gh` 命令行工具的功能、命令示例、用例说明与参数限制，作为 DeepSeek Harness 插件的需求、UI、实现与测试依据。完整用例目录见 `docs/用例目录/README.md`。

## 2. 功能总览
- 认证与状态：auth login/status/token。
- 仓库管理：create/clone/view/list/edit/delete/fork/sync。
- Issue：create/list/view/close/reopen/comment/edit。
- PR：create/list/view/merge/checkout/review/close/reopen。
- 搜索：repos/issues/prs/code。
- Actions：workflow/run。
- Release：create/list/view。
- API 与扩展：api/gist/label/alias。

## 3. 用例分层
| 层级 | 用例 | 前置条件 |
| --- | --- | --- |
| L0 本地/无仓库 | auth status、version、alias set、api 只读 | 安装 gh |
| L1 只读 | repo view/list、issue list/view、pr list/view、search、run list、release list | 认证 |
| L2 创建 | issue create、pr create、gist create、release create、repo create | 认证 + 仓库权限 |
| L3 变更 | issue close/edit/comment、pr merge/review/close、repo edit/delete、label 管理 | 认证 + 写权限 |

## 4. 输出契约
- 默认输出：终端表格/文本。
- `--json <fields>`：结构化 JSON，适合 Agent 消费。
- `--jq <expr>`：API 命令结果过滤。
- 退出码：0 成功，非 0 失败；未认证通常为 4。

## 5. 参数限制汇总
| 参数 | 作用域 | 类型 | 限制 |
| --- | --- | --- | --- |
| `--json` | 大多数命令 | string | 字段名以各命令帮助为准 |
| `-L, --limit` | list/search | int | 默认 30，最大按命令分页 |
| `--state` | issue/pr list | enum | open/closed/all 或 open/closed/merged/all |
| `--sort` | search | enum | stars/forks/updated |
| `--order` | search | enum | asc/desc |
| `-R, --repo` | 通用 | string | `[HOST/]OWNER/REPO` |
| `--base/--head` | pr create | string | 分支名 |
| `--merge/--squash/--rebase` | pr merge | enum | 三选一 |
| `--public/--private/--internal` | repo create | enum | 可见性 |
| `--yes` | delete 类 | bool | 跳过确认 |
| `--web` | view/browse | bool | 打开浏览器 |

## 6. 典型用户故事
1. 作为用户，我想查看当前 gh 登录账号和权限范围。
2. 作为用户，我想创建仓库并推送本地代码。
3. 作为用户，我想查看仓库、issue、PR 和运行状态。
4. 作为 Agent，我想通过 JSON 读取 issue/PR 列表并创建评论。
5. 作为 Agent，我想搜索 GitHub 仓库并读取搜索结果。
6. 作为用户，我想合并 PR、创建 release 并打标签。
