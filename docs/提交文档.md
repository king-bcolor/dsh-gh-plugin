# gh CLI DeepSeek Harness 插件 — 提交文档

## 1. 提交前检查
- [ ] 用例目录、用例文档说明、需求文档说明、UI 控件文档说明、实现文档已入库。
- [ ] TDD 测试全绿：`npm test`。
- [ ] 包可直接加载：`node -e "import('./index.js').then(m => console.log(m.name))"`。
- [ ] 本地验收：`DSH_HOME=$PWD/.dsh-test dsh --profile demo --dump-config`。
- [ ] 中英文 README 开头互相引用。
- [ ] 无 token/密钥入库。

## 2. gh 创建并推送仓库
```bash
cd dsh-gh-plugin
git init
git add .
git commit -m "test: add failing tests for gh plugin"
git commit -m "feat: implement gh CLI tools for DeepSeek Harness"
gh repo create dsh-gh-plugin --public --source=. --remote=origin --push
```

## 3. 标签策略
### 3.1 同类插件标签调研
- 官方必加：`dsh-plugin`。
- 同类 CLI/工具插件常用：`deepseek-harness`、`gh`、`github-cli`、`cli`、`agent-tool`、`github`、`automation`。
### 3.2 设置命令
```bash
gh repo edit <owner>/dsh-gh-plugin \
  --add-topic dsh-plugin \
  --add-topic deepseek-harness \
  --add-topic github-cli \
  --add-topic gh \
  --add-topic cli \
  --add-topic agent-tool
```

## 4. 用户集成方式
```bash
# GitHub 直装
dsh plugin --profile default add github:<owner>/dsh-gh-plugin
# 锁定 commit
dsh plugin --profile default add github:<owner>/dsh-gh-plugin#<sha>
# npm / tarball
npm publish
dsh plugin --profile default add dsh-gh-plugin
```
启动：`dsh --profile default`。

## 5. 发布清单
```bash
npm test
dsh plugin --profile gh-accept add .
dsh --profile gh-accept --dump-config
git tag v0.1.0 && git push origin v0.1.0
gh release create v0.1.0 --generate-notes
```
